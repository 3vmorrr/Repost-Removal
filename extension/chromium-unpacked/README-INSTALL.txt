# Chromium Developer Mode build

This directory is a ready-to-load Chrome/Edge Chromium extension build. It contains `manifest.json` at its top level; select this folder using **Load unpacked**. The source and build instructions are in [`../README.md`](../README.md) and [`INSTALLATION.md`](INSTALLATION.md).

For the ZIP package, download `tiktok-repost-remover-chromium-v2.2.0.zip` from the repository's [v1.1.0 release](https://github.com/3vmorrr/Repost-Removal/releases/tag/v1.1.0), extract it, and load the extracted folder.

This project preserves its upstream MIT license and author attribution in the parent folder. It is not a Chrome Web Store or Edge Add-ons publication.
