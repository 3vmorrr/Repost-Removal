Repost Remover v1.1.0

This repository release organizes the projects under /desktop, /android, and /extension.

Assets:
- Windows x64 installer and portable app: desktop application 1.0.0 (unsigned).
- Android APK: 1.0.0-alpha1 debug-signed preview. Not production or Play Store signed.
- Chromium extension ZIP: load unpacked in Chrome or Edge Developer Mode. The repository also contains extension/chromium-unpacked for direct local loading.
- Firefox desktop extension ZIP: separate package; see extension/INSTALLATION.md for limitations.

To install the Chromium extension, extract the ZIP, open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json. For an extracted repository checkout, select extension/chromium-unpacked.

The extension is not published to a browser store. TikTok repost actions use private website endpoints that can change or be restricted.
